Wasmer 1.0 is now generally available Runtime and compiler performance is out of this world. New features include better error handling, a more powerful API, cross-compilation, headless Wasmer and so much more! It’s been two years since we published the first line of Wasmer code, the first server-side WebAssembly (Wasm) runtime able to run Nginx server-side .
